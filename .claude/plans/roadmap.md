# Roadmap — zion-minecraft-agents

## Now (v1.0)
- [x] Core agent pipeline (orchestrator → mod/world/lore → deploy)
- [x] Kid-friendly web UI
- [x] One-click launcher
- [x] Auto-permissions (no popups)
- [x] AGI-1 framework integration
- [x] CI/CD validation pipeline

## Next (v1.1)
- [ ] Voice input (Web Speech API) for Zion to speak requests
- [ ] Mod history panel showing past creations
- [ ] "Undo last mod" button (restore from backup)
- [ ] RCON integration for `/reload` without full restart

## Future (v2.0)
- [ ] VPS deployment support (server_mode: vps)
- [ ] Multi-world support (creative vs survival server)
- [ ] Mod marketplace — Zion can browse past mods and re-enable them
- [ ] Daily theme system — AI suggests a mod idea each morning
